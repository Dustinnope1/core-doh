# CORE-DOH — Tablet Install

## One-tap / split installer
1. On the tablet, open this repo: github.com/Dustinnope1/core-doh
2. Tap Code > Download ZIP. Or in your split installer app, download everything from this repo in one go.
3. Unzip it, open `index.html` in Chrome.
4. Chrome ⋮ > Add to Home screen. That's your Core-doh icon — use `core-doh-icon.jpg` if your installer asks for an icon.

## Local brain (PocketPal)
1. Install PocketPal AI from F-Droid / GitHub.
2. Download on Wi-Fi: `dolphin-2.9.2-mistral-7b-Q4_K_M.gguf` or `Meta-Llama-3.1-8B-Instruct-Q4_K_M.gguf`.
3. Load it, new chat named Core-doh, paste `CORE_DOH_SYSTEM_PROMPT.md` as System Prompt.
4. Temp 0.8, Top P 0.95, Context 8192.
5. Chat in PocketPal. Offline after download.
